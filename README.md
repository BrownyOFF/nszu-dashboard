# 🏥 НСЗУ: Аналітика та Аудит

**НСЗУ: Аналітика та Аудит** — це набір веб-інструментів для обробки, конвертації та глибокого візуального аналізу медичних звітів Національної служби здоров'я України (НСЗУ).

## 📌 Огляд проєкту
Проєкт розроблений для автоматизації роботи з великими обсягами даних НСЗУ. Головна особливість — **повна конфіденційність**. Усі обчислення та обробка файлів відбуваються виключно на стороні клієнта (Client-side) у вашому браузері. Дані нікуди не передаються.

## 🛠 Технологічний стек
- **Основа:** Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Дизайн:** Власна CSS-система з використанням CSS Variables та шрифту *Plus Jakarta Sans*.
- **Бібліотеки (через CDN):**
  - [SheetJS (xlsx.js)](https://sheetjs.com/) — для парсингу XLSX файлів.
  - [Chart.js](https://www.chartjs.org/) — для побудови інтерактивних графіків.
- **Збереження даних:** `localStorage` для налаштувань тарифів.

## 📂 Структура та компоненти

### 1. ⚙️ Розумний Конвертер (`converter.html`)
Дозволяє швидко перетворити важкі `.xlsx` звіти НСЗУ у легкий формат `.json`. Це необхідно для миттєвого завантаження даних в аналітичну панель.
- Підтримка Drag-and-drop.
- Автоматична конвертація всіх листів книги Excel.
- Генерація JSON-файлу для завантаження.

### 2. 📊 Дашборд Аналітики (`index.html`)
Основна SPA-панель (Single Page Application) для аналізу отриманих даних.
- **Загальний огляд:** Ключові показники успішності та тренди.
- **Аудит помилок:** Детальний аналіз причин відхилення записів (з парсингом вкладеного JSON із текстових полів).
- **Фінансовий вплив:** Розрахунок зароблених та втрачених коштів на основі гнучкої системи тарифів.
- **Аналіз по лікарях:** Рейтинги за доходом, навантаженням та кількістю помилок.
- **Портрет пацієнта:** Демографічні дані, з акцентом на дитяче населення (0-17 років).
- **Реєстр записів:** Зручна таблиця з пагінацією та підказками щодо кодів помилок.

## 🗄 Робота з даними (Data Mapping)
Система має інтелектуальний мапінг колонок. Вона автоматично шукає необхідні дані (ID, дата, лікар, пакет послуг, статус звіту, помилки тощо), навіть якщо порядок стовпців у файлі НСЗУ зміниться.

## 💰 Бізнес-логіка
У додатку реалізовано динамічну систему оцінки вартості послуг. Ви можете самостійно налаштувати тарифи для різних пакетів НСЗУ у вкладці "Налаштування". Ці зміни будуть збережені у вашому браузері.

## 🚀 Як почати користуватися
1. Відкрийте `converter.html` та завантажте ваш `.xlsx` звіт від НСЗУ.
2. Завантажте згенерований `.json` файл.
3. Відкрийте `index.html` та виберіть отриманий `.json` файл.
4. Досліджуйте аналітику!
