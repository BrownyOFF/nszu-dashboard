# 🏥 НСЗУ: Аналітика та Аудит

**НСЗУ: Аналітика та Аудит** — це потужний набір веб-інструментів для обробки, конвертації та глибокого візуального аналізу медичних звітів Національної служби здоров'я України (НСЗУ). Проєкт перетворює "сухі" таблиці на стратегічні інсайти, допомагаючи медичним закладам управляти фінансами, якістю даних та ефективністю персоналу.

---

## 📌 Основні можливості

- **⚙️ Розумний Конвертер (`converter.html`):** Перетворення об'ємних `.xlsx` звітів у легкий `.json`.
- **📊 Інтерактивний Дашборд (`index.html`):** 9 спеціалізованих вкладок для глибокого аналізу.
- **🌙 Темна тема:** Повноцінний нічний режим з адаптацією всіх графіків.
- **🛡️ Повна конфіденційність:** Усі обчислення (Client-side) відбуваються в браузері.
- **💰 Фінансова гнучкість:** Настроювані тарифи для кожного медичного пакету.

---

## 🚀 Швидкий старт

Для коректної роботи локальних скриптів використовується вбудований Python-лаунчер.

1. Встановіть **Python 3**.
2. Запустіть файл відповідно до вашої ОС:
   - **Windows:** `start.bat`
   - **Linux/macOS:** `sh start.sh`
3. Браузер автоматично відкриє `main.html`.

## 📂 Детальний огляд вкладок та логіка розрахунків

### 1. 🏠 Загальний огляд
*Центральні метрики стану закладу за обраний період.*
- **Всього записів:** Загальна кількість рядків у звіті.
- **Успішність (%):** Відношення записів зі статусом "Так" (включено до звіту) до загальної кількості.
- **Тренд записів (Line Chart):** Групування кількості візитів за датами для відстеження щоденної активності.
- **Статус оплати (Doughnut):** Співвідношення прийнятих та відхилених записів.

### 2. 🚨 Аудит помилок
*Глибокий технічний аналіз причин відмов НСЗУ.*
- **Критичні помилки (Bar Chart):** ТОП-10 текстових коментарів помилок за частотою.
- **Діаграма Парето (Фінансові втрати):** Комбінований графік (Bar + Line). Стовпчики показують суму втрачених грн за кожним типом помилки. Лінія показує кумулятивний відсоток. Допомагає знайти 20% типів помилок, що спричиняють 80% втрат.
- **Специфічні причини:** Парсинг вкладеного JSON з колонки "Деталі" для виявлення технічних кодів помилок.

### 3. 🧬 Клінічний аналіз
*Аналіз структури захворюваності та якості кодування.*
- **ТОП за доходом (₴):** Діагнози, які принесли закладу найбільше коштів.
- **Ризикові діагнози (%):** Діагнози, за якими найчастіше приходять відмови (Помилки / Усього по діагнозу).
- **Класи МКХ-10 (Doughnut):** Автоматичне групування діагнозів за латинськими літерами (A-B — Інфекції, C-D — Новоутворення тощо) згідно зі стандартами ВООЗ.

### 4. 💰 Фінансовий вплив
*Грошова оцінка діяльності закладу.*
- **Зароблено / Упущено:** Сума тарифів прийнятих записів проти відхилених.
- **Фінансова вага пакетів:** Порівняння прибутковості різних пакетів послуг (напр. Пакет 9 vs Пакет 4).
- **Розрахунок:** `Сума = Кількість записів * Тариф пакету`.

### 5. 👨‍⚕️ Аналіз по лікарях
*Оцінка продуктивності та якості роботи персоналу.*
- **Success Rate:** Індивідуальний відсоток успішно поданих звітів для кожного лікаря.
- **Smart-підказка:** Система знаходить для кожного лікаря діагноз, за яким він найчастіше отримує відмову, і виводить пораду.
- **Рейтинг доходу:** Гістограма прибутковості лікарів.

### 6. 👶 Портрет пацієнта
*Демографічний та поведінковий аналіз.*
- **Віковий розподіл:** Гістограма по роках (фокус на дітях 0-17 років).
- **Коефіцієнт повторних візитів:** Відсоток унікальних пацієнтів, які з'являються у звіті більше одного разу.
- **Інтенсивність:** Середня кількість послуг на одного унікального пацієнта (`Записи / Унікальні ID`).

### 7. 📅 Динаміка та Навантаження
*Часовий аналіз роботи закладу.*
- **Heatmap (Теплова карта):** Сітка "День тижня / Година доби". Інтенсивність кольору залежить від кількості внесених записів. Допомагає виявити "години пік".
- **Порівняння періодів (MoM):** Система автоматично зберігає результати кожного завантаженого звіту в локальну історію (`localStorage`).
- **Гнучке порівняння:** Користувач може обрати будь-які два місяці (навіть із різних файлів, завантажених раніше) для порівняння доходу та кількості записів. Динаміка розраховується автоматично при зміні вибору в селекторах.

### 8. 📄 Реєстр записів
*Операційна таблиця з усіма даними.*
- **Smart Tooltips:** При наведенні на помилку, система шукає опис коду у довіднику "Опис помилок" (якщо він був у Excel).
- **Експорт CSV:** Вивантаження поточної відфільтрованої таблиці для подальшої роботи в Excel.

### 9. ⚙️ Налаштування
- **Керування тарифами:** Можливість задати ціну за одиницю послуги для кожного пакету НСЗУ окремо. Дані автоматично зберігаються в `localStorage` браузера.
